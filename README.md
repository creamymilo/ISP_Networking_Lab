# ISP Engineering Lab

A practical home lab focused on networking, Linux, ISP routing, and network automation.

This repository documents my hands-on journey from network support toward ISP and network engineering. The goal is to build a strong foundation through practical labs, troubleshooting, and experimentation with technologies used in real-world networks.

## Lab Environment

My lab uses a low-power virtualisation environment and MikroTik networking equipment.

| Component           | Purpose                                    |
| ------------------- | ------------------------------------------ |
| Proxmox VE          | Virtualisation and lab infrastructure      |
| Linux               | Linux administration and networking        |
| MikroTik RouterOS   | Routing, firewalling, and network services |
| Pi-hole             | DNS filtering and network services         |
| WireGuard           | Secure remote access to the lab            |
| FRRouting (planned) | Dynamic routing, OSPF, and BGP             |

## Current Focus

### Networking and CCNA

* IPv4 addressing and subnetting
* VLANs, trunking, and inter-VLAN routing
* Switching and spanning tree
* Routing tables and static routing
* Network troubleshooting

### Linux Networking

* Linux interfaces, bridges, and routing tables
* IP addressing and connectivity testing
* Packet analysis
* Building multi-router lab topologies

### ISP Routing and Core Networking

* FRRouting (FRR)
* OSPF and BGP
* eBGP peering and route advertisement
* Prefix filtering and routing policy
* ISP edge and customer routing concepts

### Network Automation

* Python fundamentals for network engineering
* Automating connectivity and routing checks
* Generating network status reports
* Exploring API-based network management
